# BakeU Mobile

Начальная структура отдельного приложения **React + TypeScript + Capacitor** для
Android и iPhone. Сейчас здесь только каркас: маршруты, страницы-заглушки,
базовая навигация, настройки сборки и native-проекты. Каталог, авторизация,
корзина, заказы, чат, платежи и push-уведомления ещё не реализованы и не подключены
к серверу. Это не готовая к публикации сборка магазина.

## Быстрый запуск

Нужен Node.js **24 LTS** (`.nvmrc` приложен для пользователей nvm). Команды выполняются внутри `mobile/`, не в корне сайта:

```sh
cd mobile
npm ci
npm run dev
```

Откройте **http://127.0.0.1:4300/**. Порт отделён от сайта и API. Если он занят,
можно выбрать другой: `npm run dev -- --port 4302`.

```sh
npm run check
```

Команда проверяет ESLint, TypeScript и создаёт web-сборку в `dist/`. Нативные
проекты берут именно эту сборку; адрес Vercel в приложение не зашит.

## Синхронизация с Android и iOS

После изменения React-кода web-сборку нужно передать native-проектам:

```sh
npm run sync
```

Для одной платформы: `npm run sync:android` или `npm run sync:ios`.

**Android, Windows или Mac:** установите Android Studio, JDK 21 и Android SDK 36, затем:

```sh
npm run android
```

**iPhone, только Mac:** установите совместимый с Capacitor 8 Xcode. Проект использует Swift Package Manager (без CocoaPods), затем:

```sh
npm run ios
```

Проекты `android/` и `ios/` уже созданы; повторно выполнять `cap add` не нужно.
В Linux-среде можно проверить web-сборку и файлы проектов, но здесь не выполняется
сборка APK/AAB или IPA, не запускаются симуляторы и не настраивается подпись.
Проверка native-инструментов на вашей машине: `npm run doctor`.

## Настройки и следующий этап

- Черновой идентификатор обеих платформ: `uz.bakeu.mobile`. Перед первой
  публикацией его нужно окончательно выбрать и согласовать во всех native-
  настройках, а также заменить стандартные native-иконки и splash screen.
- `.env.example` содержит только место для **публичного** адреса API. На текущем
  этапе приложение не делает сетевых запросов. Токены бота, приватные API-ключи и
  ключи подписи в React-код и Git не добавляются.
- Данные существующего сайта и его демо-админки не копируются в приложение.
  Реальные аккаунты и заказы подключим к общему HTTPS API отдельным этапом.
- Камера, геолокация, push и платежи пока не запрашивают разрешений: соответствующие
  native-плагины подключаются только при реализации этих функций.
- Для публикации позже понадобятся Google Play Console, Apple Developer /
  App Store Connect, подпись и тестирование на реальных устройствах.

Исходники и настройки платформ отслеживаются Git. `node_modules/`, `dist/`,
сгенерированные web-копии внутри native-проектов, IDE-кэш, SDK-пути, native build-
результаты, приватные `.env` и файлы подписи не коммитятся. После клонирования
выполните `npm ci`, затем `npm run sync`, чтобы восстановить bundled web assets.

Native-цели шаблона: Android API 24+ (compile/target SDK 36) и iOS 15+.
Стартовая версия web/Android/iOS согласована как `0.1.0`, build number — `1`.
Все native-иконки и splash screen пока стандартные из шаблона Capacitor.
